درباره BLACKBOX

BLACKBOX یک پروژه کوچک آموزشی برای تمرین مفاهیم پایه امنیت وب است.

GitHub Pages فقط فایل‌های استاتیک را میزبانی می‌کند. بنابراین این نسخه دیتابیس سروری، API واقعی یا احراز هویت امن ندارد. اطلاعات کاربران در localStorage مرورگر ذخیره می‌شود و پاک‌کردن داده‌های سایت آن‌ها را حذف می‌کند.

برای حساب‌های واقعی یا اطلاعات حساس از این نسخه استفاده نکن. کد HTML و JavaScript برای بازدیدکنندگان قابل مشاهده است.
